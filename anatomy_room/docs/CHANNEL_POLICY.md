# チャンネル方針（CHANNEL_POLICY）

## 基本情報

| 項目 | 内容 |
|------|------|
| チャンネル名 | **世界の解剖室** |
| キャッチコピー | **見えない仕組みを、CGで解き明かす。** |
| 形式 | YouTube Shorts（縦型 9:16） |
| 尺 | 60〜90 秒を基本。テーマに応じて最適な長さを判断する |
| 出演 | M（男性役）と W（女性役・名前は未定）の 2 人の掛け合い |

## 目的

日常生活・科学・テクノロジー・自然・歴史・社会などで、普段は意識しない仕組みを
CG・3D アニメーション・図解で可視化する。

見終えた視聴者に、次のどれかを感じてもらうことを目指す。

- 「なるほど、そういう仕組みだったのか！」
- 「えっ、そんなことになっていたの？」
- 「このチャンネルの別の動画も見てみたい！」

## 作り方の原則

1. **雑学の羅列にしない。** ひとつの疑問を出発点に、原因と結果をつなぎ、最後に納得できる答えを出す。
2. **1 本 1 疑問。** テーマは広く扱うが、各動画はひとつの疑問に集中する。
3. **映像にも情報を持たせる。** ナレーションを聞かなくても、映像だけで「何が起きているか」がある程度わかるようにする。
4. **見えないものを見せる手法**を使い分ける。
   - 断面・透視（物体の内部を見せる）
   - 逆再生（結果から原因へさかのぼる）
   - 条件を変えたシミュレーション（「もし〜がなかったら」）
   - 比喩 CG（データを小包に見立てる等）。※比喩であることが伝わるように演出する
5. **正確性は面白さと同じくらい重要。** 詳細は `FACT_CHECK_POLICY.md`。

## 扱うテーマ

- 日常に隠れた仕組み
- インターネットや情報技術
- 科学・物理・数学
- 人体や生物の仕組み
- 自然現象
- 物流・交通・インフラ
- 歴史的な発明や技術
- 社会を動かすシステム
- 直感と異なる現象や意外な事実

## テーマ選定の基準

| 基準 | 確認すること |
|------|-------------|
| 検証可能性 | 公的機関・規格・論文・技術文書など、信頼できる資料で主な事実を裏付けられるか |
| 映像化のしやすさ | 「見えない部分」を CG で見せる価値があるか。1 カット 1 情報に分解できるか |
| 面白さ | 冒頭 3 秒で「えっ？」と思わせる問いを立てられるか。途中に理解の転換があるか |
| 独立性 | 既存の動画と分野・CG 手法・掛け合いの型が重複しすぎないか |
| 安全性 | 事故・医療・災害など、誤解が実害につながるテーマでは特に慎重に扱う |

企業の内部情報に依存するテーマ（例：特定チェーンの物流の詳細）は、公開資料で検証できる範囲に絞るか、別の切り口に変える。

## 動画の基本仕様

### 映像
- 縦型 9:16（1080×1920 を想定）
- CG・3D アニメーション・図解が中心。内容に合わせて、シンプルな図解とリアル寄りの CG を使い分ける
- 比喩的な表現（光の粒、小包、キャラクター化など）には、必要に応じて「イメージ」「※模式図」の表示を入れる

### 音声
- M と W の 2 人の掛け合い。キャラクターごとに声を区別する
- 自然な日本語の口語

### 字幕
- スマートフォンで読みやすいサイズ。1 画面 2 行・1 行 16 文字程度までを目安
- 長文を一度に出さない。発話と同期させる
- 重要な単語・数値を強調する（台本では **太字** で指定）
- 数値や断定に条件が付く場合は、画面の端に注記（例：「※総務省『情報通信白書』で紹介された調査結果」）

- CG 生成、音声合成、動画ファイルの書き出し
- YouTube へのアップロード・公開
- 外部サービスへの課金
- 認証情報の要求・保存
