# 全動画共通のエンディング仕様（ENDING_SPEC）

> 2026-10-26 制定。**今後のすべての動画で必ず使う**。実装は `production/common/ending.js`（映像）と各話の `production_script.py`（音声）。

## 決めゼリフ

**「リバース。世界の仕組みを、はじめから。」**

## 音声

| 項目 | 仕様 |
|------|------|
| 話者 | **その動画の本編で使っている W（女性・ウラ）と同じ声**。別のナレーター・別の音声モデルに変えない（第 1 話＝冥鳴ひまり、第 2 話＝波音リツ、第 3 話（pilot_006）以降＝冥鳴ひまり） |
| スタイル | その話者の「ノーマル」 |
| 間 | 「リバース。」と「世界の仕組みを、はじめから。」を別々に合成し、**間に 0.5 秒の無音**を入れる |
| 話し方 | 「リバース」は抑揚をやや強め（知的で印象に残る）。「世界の仕組みを、はじめから」は話速を落とし（約 0.9）、落ち着きと余韻を出す |
| 音量 | 本編のセリフと同じ基準に正規化し、BGM はエンディング中さらに下げる。語尾まで聞き取れること |
| 重なり | 本編の最後のセリフが終わってから 0.6 秒以上空けて始める |

## 映像

| 項目 | 仕様 |
|------|------|
| 長さ | 約 4 秒（3〜5 秒）。決めゼリフの長さに合わせ、最後に 0.8 秒の余韻 |
| 切り替え | 本編の後、白い閃光のワイプでエンディング専用の画面に切り替える |
| 背景 | **明るい**：白〜淡い水色のグラデーションに、ブランドの水色と、アクセントのオレンジの光の輪（暗い背景に文字を置くだけの演出にしない） |
| 主役 | 大きな **「リバース」**（濃紺の文字）。「巻き戻し」を表す反時計回りの円弧の矢印が回り込み、文字は右から左へ巻き戻るように現れる |
| サブタイトル | **「世界の仕組みを、はじめから」**。2 句目の音声と同時に表示 |
| ブランド | 第 1・2 話：下部に小さく、解剖された立方体のマークと「世界の解剖室」、音声クレジット。第 3 話以降：チャンネル名が「リバース」になったため、大きな「リバース」をロゴとし、下部は音声クレジットだけ（`drawEnding` の `brand: ""`） |
| 字幕 | 決めゼリフは画面の大きな文字がそのまま字幕を兼ねる（通常の字幕枠は出さない） |
| 統一感 | 本編と同じブランドの水色・オレンジ・濃紺、Noto Sans CJK JP |

毎回同じ基本演出を使う。変えてよいのは、話者（その回の W）とクレジットの表記だけ。

**テクノ版（第 3 話以降、`drawEnding` の `techno: true`）**：基本の演出は同じまま、薄い格子・四隅の枠・走査線を重ね、「リバース」の出だしに一瞬のグリッチを入れる（本編のテクノの世界観からアウトロだけ急に雰囲気が変わらないように）。BGM はエンディング中、パッドとアルペジオだけに整理する。

## 確認項目（毎回の品質検証）

- [ ] 決めゼリフの音声が完成動画に入っている（エンディング区間の音量を測る）
- [ ] 本編の最後のセリフと重なっていない
- [ ] 画面の「リバース」「世界の仕組みを、はじめから」がそれぞれ音声と同期している
- [ ] 動画の最後まで音声が切れずに再生される（最後の 0.5 秒まで音声トラックがある）

## チャンネル名との関係

2026-10-26、ユーザーの指示でチャンネル名は **「リバース」**、タグラインは **「世界の仕組みを、はじめから。」** になった（第 3 話の依頼）。
エンディングの大きな「リバース」がそのままチャンネルのロゴになる。第 1・2 話のエンディングの「世界の解剖室」の表記は、作り直すときに変える（未対応）。
アイコン・ヘッダー（`branding/`）は「世界の解剖室」のまま（未対応）。
