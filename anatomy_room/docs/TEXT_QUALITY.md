# 画面の文字の品質（TEXT_QUALITY）

> 2026-10-26 制定。チャンネル「リバース」の第 3 話以降（pilot_006〜）に適用。
> 吹き出し・札・字幕・図解の文字に、文字切れ・文字化け・はみ出し・重なりを残したまま完成にしない。

## 1. 自動検査（毎回）

`python3 production_script.py textcheck`（`all` / `update` にも含まれる）。全編を 0.1 秒ごとに描き、`production/common/stage.js` が記録した
「文字を描いた範囲」を調べる。結果は `work/textcheck.json` と `qc_report.md` の「文字の自動検査」。

| 検査 | 内容 |
|------|------|
| 安全領域の外 | 文字が x 40〜1040・y 170〜1650 の外にはみ出していないか（上：検索・メニュー、下：タイトル・説明欄に隠れやすい） |
| 右側のボタン列 | x 950 より右・y 880〜1650（いいね・コメントなどのボタン）にかかっていないか |
| 入れ物からのはみ出し | 漫画の吹き出し（ギザギザ）・複数行の札・字幕の帯の内側に、文字が完全に収まっているか |
| 文字どうしの重なり | 別の文字（別の札・吹き出し）と 12% 以上重なっていないか |
| キャラクターへのかぶり | 文字の面積の 10% 以上、または 1 文字の半分ほど以上がオモテにかぶっていないか（長い注記の端の 1〜2 文字が隠れるのも拾う） |
| 声の波形へのかぶり | 文字の面積の 5% 以上が、ウラの声の波形（右上）と重なっていないか（2026-10-26 追加：QR の回で冒頭の問いが波形に重なっていたのを目視で見つけたため） |
| 大きな ×・吹き出しに隠れる | `Stage.bigX`・`Stage.burst`（ギザギザの本体）より前に描いた文字の 5% 以上が、その範囲に入っていないか（× で値札や見出しが読めなくなるのを防ぐ。わざと × で消す記号だけ `ctx.__noCheck` で外す） |
| 小さすぎる文字 | 26px 未満の文字、44px 未満に縮んだ字幕はないか |
| フォントにない文字 | 使った全文字が Noto Sans CJK JP に含まれているか（fontconfig の文字一覧で確認。含まれない記号は別の文字に置き換える。例：✕ → ×） |

- 0.3 秒以下（3 コマ以下）しか続かないものは、飛び出し・切り替えのアニメーションの途中として「一時的」と分けて記録する（目視で確認する）。
- 背景の飾り（降ってくる値札など）は検査から外す（`ctx.__noCheck`）。その場合も、主要な文字は飾りより上に、地の色付きの札で描く。
- 自動検査は完了の判定ではない。最後は必ず、書き出した動画を全編、目視で確認する。

## 2. 作り方の決まり

- **吹き出し（ギザギザ）**：`Stage.burst` は文字の幅に合わせて大きさを自動で決める（文字が輪郭に触れない）。
- **複数行の札**：`Stage.panel` を使う（行の幅に合わせて札の大きさを決める）。札の上に別の文字を手で重ねて置かない。
- **字幕**：幅 780px まで（中心 x 490）。はみ出す場合は 44px までしか縮めず、それより長い字幕は `sub` を配列にして分割する（例：pilot_008 の L18）。
- **表示時間**：字幕のかたまり 1 つは、画面に出ている時間で 0.7 秒以上を目安。短すぎるものは前後とまとめる（qc_report の「字幕の表示時間」。字幕は次のセリフが始まるまで、最大で話し終わりの 0.4 秒後まで残るので、その時間で測る）。
- **ウラの声の波形**は右上（x≈810〜1050・y≈270〜330）に固定。大きくしたり画面の中へ動かしたりしない（ウラは姿を出さない）。見出しはその左側に収める。
- **大きな ×** は、消す対象の文字を読めなくしない大きさ・位置で（文字の横に小さく押す、など）。
- **大事な数字・結論**は画面の中央寄り（安全領域の内側）に置く。注記は上（y≈230〜330）か、字幕の上（y≈1200〜1270）に置く。
- 環境によって崩れやすい絵文字は使わない。記号はフォントに含まれるもの（→ × ○ ⚠ ≠ ①②③ など）を使い、検査で確認する。
- 文字の縁取り・影・発光は、読みやすさを損なわない範囲で使う。

## 3. 目視チェック（書き出した動画で毎回）

`python3 anatomy_room/tools/video_qa.py pilot_00N --sheets` で、字幕の欠落・最初のコマ（自動のサムネイル）の自動検査と、目視用の一覧 `qa/sheet_*.jpg` を作る。記入は `templates/VIDEO_QA_CHECKLIST.md`。

1 秒ごとのコマを並べた一覧（`ffmpeg -vf fps=1`）で全編を見る。冒頭・途中・終盤のすべてで：

- [ ] 吹き出し・札・字幕の内側に文字が収まっている／上下左右が切れていない
- [ ] 文字化け・誤字がない／セリフと表示テキストが一致している
- [ ] 文字がキャラクター・図解・ほかの文字に不自然に重なっていない
- [ ] 改行の位置が自然／文字が小さすぎない／表示時間が短すぎない
- [ ] エンディングのロゴ・タグライン・クレジットが正しく出ている

問題があれば直して書き出し直し、もう一度確認する。
