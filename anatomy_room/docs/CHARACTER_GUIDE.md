## オモテ（M・男性）— 破天荒な実験台

### 人物像
- 好奇心が異常に強く、思いついたらすぐ実行する。危険や異常事態に、普通の人とは違う行動を取る。
- 自分の推理には妙な自信がある（「俺の読みだと、換気口だ」）。状況が悪化しても口だけは達者。
- 追い詰められるほど、妙に冷静なツッコミを入れる（「……左腕が、ない」「この検証、俺が飛び出す必要、あったか？」）。
- 自分が実験台にされていると気づいても、なぜか検証を続ける（「俺、今、論文どおりに動いたのか」）。
- ウラに言い負かされるが、簡単には認めない（「換気口説、半分当たりだ」）。
- **ただのバカではない**。頭の回転は速く、発想も大胆。重要な仮説・鋭い質問・意外な気づきを、毎回少なくとも 1 つ持たせる
  （例：「すき間も機内と同じ気圧になる。だから真ん中は押されない！」「十から三と二を引けば、五だ！」「どこを、どれだけ消すか、ってことか」）。
- 巻き込まれるのは偶然だけでなく、本人の無謀な判断が原因のこともある（自分で消しゴムを持つ、角まで消しにいく）。

### 話し方
- 短く、言い切る。パニックは「熱血」スタイルで大声、冷静なツッコミは「不機嫌」スタイルで低く。
- 方向性の例（毎回そのまま使い回さない）：「いや、待て。俺の予想だと〜」「お前、最初から知ってただろ！」「知識を得るために失うものが多すぎる！」

### 声（VOICEVOX）
- **青山龍星**（第 2 話から維持。低音で、落ち着きと存在感のある声）。スタイル：ノーマル（normal）、不機嫌（dry）、熱血（hot）、囁き（whisper）。
- 話速 約 1.22（第 2 話は 1.03）。テンポは「話速」と「セリフの間」で上げる。

### 見た目（映像）— 3D ピクトグラム（v3.1）
- コンセプト：**「シンプルなのに、なぜか愛着が湧く」**。three.js で描く立体のピクトグラム（`production/common/stage.js` の `omote3`）。
- 形：オレンジの光沢のある球の頭＋カプセルの胴・手足。頭のてっぺんに **アンテナのような 1 本の毛**（先が水色に光る）、胸に **光るリング**。シルエットだけでオモテと分かることを優先し、細部は増やさない。
- 表情：目（白＋黒目）・まゆ・口の形だけで出す（ふつう・ドヤ顔・驚き・パニック・目を回す（×目）・考える・ジト目・笑顔）。
- 動き：伸びる・縮む（sx／sy）、傾く、回る、跳ねる。体の向き（yaw）は視線の方向に少しひねり、立体感を見せる。QR の回ではこの 3D モデルをドット絵にする。
- 過度に幼児向けにしない：色数を絞り（オレンジ＋水色の発光）、テクノの世界観に合わせる。旧 2D 版は `omote2d` として残している。

## ウラ（W・女性）— 毒舌の解説者

### 人物像
- 知識が豊富で、頭の回転が速い。皮肉と毒舌を好む。オモテの無謀な行動を冷静に観察し、面白がっている。
- 基本的にはオモテを助けない。オモテがひどい目に遭っても、解説を優先する。ときどき助けるが、助け方にも嫌味が混じる（「ご褒美に、目印を描き直してあげる」）。
- 相手の発言の矛盾を即座に見抜く（「一番大事な『外に』が外れてるけど」）。
- 長々と説教しない。短く鋭い一言で笑わせる。
- 知識を説明するときは生き生きとし、発見の面白さを楽しむ。
- **毒舌は人格否定ではない**。オモテの発言・行動の矛盾を突く知的なユーモアにする（例：「その仮説、窓より穴だらけね」「冴えてるわね。腕はないのに」「実験は大成功ね。あなたの財布以外は」）。

### 声（VOICEVOX）
- **冥鳴ひまり**（第 1 話で使っていた女性の声に戻した。ユーザーの指示）。スタイルは「ノーマル」のみ。
- 冥鳴ひまりはスタイルが 1 つしかないため、表情は **話速・抑揚・間** で付ける（既定：話速 1.32、抑揚 1.15。毒舌の決めの行は抑揚 1.3〜1.35、オチは話速を少し落とす）。
- 共通エンディング「リバース。世界の仕組みを、はじめから。」もウラの声。

### 見た目（映像）— 姿は出さない（v3.1）
- **ウラの 3D モデル・立ち絵・顔アイコン・人型の姿は画面に一切出さない**。声とセリフだけで存在させる。
- ウラが話している間だけ、右上に小さな **声の波形**（`stage.js` の `wipe2`）と、字幕の話者名「ウラ」を出す。これはウラの姿ではなく、誰が話しているかの表示。
- ウラの発言に合わせた文字演出・図解・画面効果は使ってよい（ウラ自身の姿としては見せない）。魅力は知識量・鋭いツッコミ・皮肉・間・声の表現で伝える。
- 旧版の胸像（`uraBust`）は第 3〜5 話の旧版（`versions/v1_pop`）だけで使っていた。

## 2 人の関係と会話のルール

1. **先生と生徒ではない**。オモテ＝知識を得るために自ら無茶をする実験者、ウラ＝知識を持ちながら、オモテの無茶を面白がる解説者。
2. ウラがすべてを一方的に説明しない。オモテが反論し、ウラがさらに鋭く返すことでテンポを作る。オモテに仮説・質問・気づきを持たせる。
3. 1 本の流れ：**疑問 → オモテが巻き込まれる → とんでもない事態 → ウラが毒舌を交えて解説 → オモテが理解する／さらにひどい目に遭う**。
4. 毎回同じ「吹き飛ぶ・落ちる・爆発する」にしない。テーマに最も合った出来事を考える（窓が抜けて巻き戻る／自分がデータになる／実験店で値札に振り回される）。
5. 最後は、内容とキャラクターの両方が残るオチ（オモテの負け惜しみ・ウラの一言）で締め、共通エンディングにつなぐ。
6. 方向性の例のセリフ（依頼文の例）は、そのまま使わず、テーマに合わせて新しく作る。
