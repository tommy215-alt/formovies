# ブランディング素材

| ファイル | 用途 | サイズ |
|---------|------|--------|
| `icon_800.png` | YouTube のプロフィール写真（円形に切り抜かれて表示） | 800×800 |
| `header_2560x1440.png` | YouTube のバナー画像 | 2560×1440 |

| `icon_preview_sizes.png` | 確認用：小さく表示したときの見え方（アップロードしない） | — |

## デザイン

- **モチーフ**：「解剖された立方体」。上面と左面は外側（白・薄い青）、右面だけ外して内側の回路を見せる。
  「見えない仕組みを、CGで解き明かす」をそのまま形にした。
- **色**：濃紺（#0A1424）、シアン（#46D3F0）、白（#EEF4FA）。背景に細かいドット格子。
- **ヘッダー**：文字とマークは YouTube の安全領域（中央 1546×423）の中に収めた。下の定規の目盛りは「計測・解剖」の意匠。
- **フォント**：Noto Sans CJK JP（SIL Open Font License）。

## 作り直し方

```bash
sudo apt install fonts-noto-cjk   # 未導入の場合
node anatomy_room/branding/render.js
```

色や文字は `render.js` の `C`、マークの形は `mark.js` で変更できる。
