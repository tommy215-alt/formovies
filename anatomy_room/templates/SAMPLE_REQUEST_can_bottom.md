# 再現テスト：テンプレートを使った制作指示のサンプル

> 目的：窓の回と違う題材でも、`MASTER_VIDEO_TEMPLATE.md` に沿えば同じチャンネルの動画になるかを、制作に入る前の指示の段階で確かめる。
> **これはサンプル（仮定）**。動画は作っていない。事実はまだ確認しておらず、すべて「要確認」。制作するときは FACT_CHECK_POLICY に従って確認し直す。

---

## 1. 入力（VIDEO_PRODUCTION_PROMPT の【入力】を埋めたもの）

```
【入力】（必須）
- 今回の題材：缶ジュース（炭酸飲料のアルミ缶）の底は、なぜへこんでいるのか
- 動画で伝えたい事実：
  - 炭酸飲料の缶は、中のガスで内側から押されている（要確認：圧力の大きさ）
  - 底をドーム状にへこませると、平らな底より内側からの圧力に強い（要確認）
  - 同じ強さなら、アルミを薄くできる＝材料が少なくて済む（要確認）
- 想定する動画の長さ：本編 65 秒前後
- 必要な追加条件：なし

【入力】（任意）
- 制作の範囲：台本まで
（ほかは未記入 → MASTER の既定を使う）
```

## 2. テンプレートを当てはめた設計（Claude が作る scene_plan の骨組み）

| 場面 | 長さ | 内容（可変 [V] として決めたこと） | 固定 [F] として守ること |
|---|---|---|---|
| cold | 0〜1.5 秒 | 机の上の缶の底が「ボンッ」と膨らみ、缶が転がる（※ギャグ演出）→ 巻き戻し | セリフなし、効果音を 3〜5 個重ねる、最初のコマは缶とオモテが見える止め絵 |
| hook | 約 5 秒 | 大きな問い「なんで底がへこんでる!?」。オモテ「底、へこんでて損してないか？」 | 上部に太い問い。ウラの波形は右上 |
| gag | 約 3 秒 | オモテが缶を振る → 缶ごと膨らんで、オモテが缶の上で弾む | 「※ギャグ演出」。原因の誤解を残さないよう、直後に訂正 |
| 間違った仮説 | 約 6 秒 | オモテ「量を少なく見せる作戦だな」（探偵ポーズ）→ ウラが否定（× は文字の横に小さく） | 腕組みでそっぽ。毒舌は人格否定にしない |
| 構造 | 約 6 秒 | 缶の断面（底のドーム）の模式図。オモテが缶の中に入って底を歩く | 「※模式図」 |
| 仕組み（数字） | 約 9 秒 | 中のガスが全方向から押す矢印。オモテが底の役になり、平らな底だと膨らむ → ドームなら押し返せる | 数字は 1〜2 個（要確認の値だけ）。「※概算」 |
| 気づき | 約 8 秒 | **オモテが**「アーチと同じで、押されるほど踏ん張れる形か！」 | 気づきはオモテ。ウラ「正解」 |
| 役割・応用 | 約 7 秒 | 薄いアルミでも耐えられる → 材料が少なくて済む | オモテは体験を続ける |
| 追加の事実 | 約 3 秒 | 重ねて置きやすい、とも言われる（要確認。確認できなければ削る） | 不確かなら「〜と言われている」 |
| オチ | 約 10 秒 | オモテ「量を少なく見せる説、半分当たりだ」→ ウラの毒舌 → BGM を止めてオモテの冷静なひと言 → 立ち直り | drop → ひと言 → 笑顔 |
| ending | 約 4.6 秒 | 共通エンディング | 変更しない |

- BGM：新しいスタイル `tech_can`（130 BPM・短調）を `TECH_STYLES` に足す想定。範囲 125〜150 BPM の中。
- 背景の色調：台所・机（暖色寄りの白）→ 断面図（水色）。明るさは保つ。
- 効果音：sweep_up＋impact＋glitch＋rewind（冒頭）、brake（缶が止まる）、discover（気づき）、zap（毒舌、2 か所まで）など、既存の bank から選ぶ。

## 3. 確認項目の自己評価

| 確認項目 | 評価 | 理由 |
|---|---|---|
| 同じチャンネルの作品だと感じられるか | ◎（設計上） | オモテの見た目・ウラの波形・明るいテクノの背景・字幕の帯・共通エンディング・テクノ BGM・掛け合いの声はすべて固定ルールのまま |
| 音声・映像・字幕のスタイルの統一 | ◎（設計上） | 声の設定（v4）、BGM の作り方とミックス、字幕の部品（stage.js）を共通で使うため、題材が変わっても同じになる |
| 新しい題材に合わせて内容を変えられるか | ○ | 事件・仮説・構造・仕組みの中身はすべて可変ルールで差し替えられた。缶の 3D は新しく作る必要がある（窓の 3D は流用できない） |
| 元動画の不要な要素までコピーしていないか | ○ | 窓・機内・米袋・WARNING・換気口説は使っていない。「巻き戻し」は冒頭のつなぎとして固定ルールの範囲で使う（毎回同じにならないよう、別の転換でもよい） |
| 字幕や吹き出しの品質を担保できるか | ◎ | 字幕・札・吹き出しは自動で大きさが決まる部品、textcheck（全編 0.1 秒ごと）、`video_qa.py`（字幕の欠落・最初のコマ）、1 秒ごとの全編目視の 3 段階 |

- **評価は「設計上」**。実際に作って見比べたわけではない。本当に同じチャンネルに見えるかは、1 本作ってユーザーが見比べて判断する。
