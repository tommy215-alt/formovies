# REVERSE 動画制作ガイドライン v2.2（2026-10-29、ユーザーの指示）

**次回以降の新作に適用する**（既存の動画は直さない）。標準ルール `REVERSE_STANDARD_RULES.md` v6 の一部。v2.1（`REVERSE_GUIDELINE_v2.1.md`）と pilot_015 の修正事項に、次の 5 点を足す。食い違うときはこのファイルを優先する。

## 0. v2.1 から引き継ぐもの（pilot_015 で入れた修正事項。既定値にする）

- BGM は安心して聴ける `warm_drive`（124 BPM、`production/ext/music_ext.py`）。場面の感情でモードを変える。
- 冒頭 3 秒は、問いと一緒に文字（`HUD.title` の大きな見出し）・効果音（`title` など）・光の演出をそろえて強く。
- 注目・拡大のときはテクノロジー感のあるアイコン（`production/ext/hud_ext.js` の `HUD.*`）。
- 効果音は多めに（1 本で 45〜65 か所）。やわらかい音色のまま。
- 話速は聞き取れる範囲で速く（目安 7.3〜7.8 モーラ/秒。pilot_015 は玄野武宏 1.12 で 7.7）。

## 1. 長さは 60〜90 秒（本編）

- 目安は本編 60〜90 秒、全体（エンディングを含む）で 95 秒以内。`lines.json` の `max_duration` は 95。
- 物語の芯（状況 → 具体的な困難 → 本人の行動 → 転機 → 結果 → 現在）を残し、説明のための説明を削る。1 行に 1 つの情報。
- 削る候補：仕組みの細部（理論の名前、2 段目の説明）、肩書や年の羅列、同じことの言い換え。
- それでも収まらない題材は、前編・後編に分ける（前編の最後に、続きを見る理由を置く）。
- 台本の段階で `production_script.py voice` を実行して尺を測り、超えたら台本を直す（映像を作る前に）。

## 2. 冒頭の最初の 1 秒に「結末の一番いい画」を見せる

- 決定的な映像（その回の核心の画）を、最初の 0.5〜1.0 秒だけ先に見せる（例：pilot_015 なら、水素の線だけが光るスペクトル）。
- そのあと冒頭の問いへ切り替える。ナレーションは 0.1 秒で話し始める（`lead_in`）。最初の一文は、その画の意味を問う形にする（例：「この一本の光が、常識を覆した。」→「太陽は何でできているのか。」）。
- 先に見せる画では答え（数字や名前）を言わない。字幕にも出さない（見出しの文字は可）。
- 実装：`renderer.html` の冒頭の場面（hook）の頭に、決定的な映像の描画を 0.5〜1.0 秒呼ぶ。効果音は `bloom` か `reveal`。

## 3. 最後を冒頭につなげる（くり返し再生を狙う）

- 最後の一文（L 最終行）は、冒頭の問いに答えを返す形にする（例：冒頭「太陽は何でできているのか」→ 最後「その答えが、いま、宇宙を知る土台になっている」）。
- 最後の画は、冒頭の最初の画と同じ構図・色に戻す（動画が頭に戻ったとき、つなぎ目が自然に見える）。BGM も最後の小節で冒頭のモードに戻す。
- エンディング（下の 5）のあと、動画の頭に自然につながるか、`qa/hook_3s.mp4` と最後の 3 秒を続けて見て確かめる。

## 4. 本物の写真を 1〜2 枚入れる（著作権の条件を満たすものだけ）

- 主人公が初めて出る場面か、決定的な場面の直前に、本物の写真（人物・場所・資料）を 1〜2 枚。ゆっくり寄る（ケン・バーンズ）・暗い縁取りで再現 CG の世界になじませ、画面に小さく「写真：出典」を出す。
- **使ってよいもの**：パブリックドメイン（アメリカの政府機関の作品、著作権の切れた作品：アメリカでは 1930 年までに発表された作品〔2026 年時点〕、日本では原則として作者の死後 70 年）、CC0、CC BY（クレジットを書く）。
- **使わないもの**：CC BY-NC（収益化するチャンネルでは使えない）、CC BY-ND（寄る・切り抜くなどの加工が問題になりうる）、ニュース映像・映画・他人の動画・有料の素材、権利の分からないもの。「引用」を理由に使わない。
- 人物の写真は、撮影者の権利が別にあることが多い。1 枚ずつ、所蔵先の権利の表示を確かめる。ロゴ（NASA のロゴなど）は使用の制限があるので映さない。
- **記録**：`scripts/pilot_NNN/assets.md` に 1 点ずつ、出典の URL・所蔵先・権利の種類・クレジットの書き方・確認日・確認方法（本文を読んだ／検索抜粋）を書く。説明文にもクレジットを書く。
- 画像のファイルは `production/pilot_NNN/assets/` に置く（file:// の画像は WebGL に渡せないので、3D で使うときは data URI の JS にする：pilot_013 の `earth_tex.js` と同じ方法）。2D に描くだけなら `<img>` で読み込める。
- 確認できる写真がない題材は、無理に入れない（CG のまま）。
