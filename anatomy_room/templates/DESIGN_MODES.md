### 知的設計の編集設定（2026-10-30〜、pilot_022 の 2 回目の直しで決定。ユーザー「次回からも知的設計は今回の編集設定で」）

上の表より優先する。参考は **pilot_022**（`production/pilot_022/renderer.html` の `CUT`・`CI`・`ciPhase()`・`ciShot()`、`production_script.py` の効果音と BGM）。

- **話速は聞き取れる限界近く**：オモテ（玄野武宏）1.5、オープニングの W（冥鳴ひまり）1.3、行間 0.03 秒（`lines.json` の `voice_override`・`gap`）。台本はそのままで約 2 割短くなる（pilot_022 は 83 秒 → 65 秒）。
- **起承転結のカットイン**（2026-10-30 の 3 回目の直しで確定。ユーザー「3 回も入ると多い」）：起・承・転・結それぞれの頭のセリフで、暗転に大きな 2 行の文字（`HUD.title`、110 相当）を 0.45 秒。
  - **起・承・結は 1 回だけ**：暗転の文字 → 本来の画。効果音は impact・deep・whoosh（戻るところ）。
  - **転だけ 3 回**：暗転の文字 → カット A（被写体の極端な寄り）→ カット B（別の角度・後ろ姿など）→ 本来の画。切れ目は 0.45／0.95／1.5 秒で、効果音（impact・deep・hit・whoosh・impact・hit）をそこに合わせる。
  - BGM は 0.5 秒前に w_hold へ引き、切れ目で入れ直す。閃光は使わない。
- **オープニング**：結論の文字＋W の声＋**題材に直接関係する本物の写真**（pilot_022 はマーシャルが飲んだ培養液の瓶、ノーベル博物館）。グロテスクな写真は避ける。音は **`open_chime`**：ベルの音色で駆け上がるアルペジオ（「チャララララーン」、ゼルダの謎解きのチャイムのような感じ。既存の曲の旋律はなぞらない自作）→ 最後の音と和音をのばす＋きらめき。`open_eerie` は「あるチャンネルの音に酷似」とされたので使わない。
- 札は文字だけ（一文字のアイコンを付けない）。共通エンディングは短い版。

## 3 つ目：「悲劇用」（2026-10-30、ユーザーが命名）

指示で「悲劇用で」と言われたら、この設定で作る。土台は v2.4 とドパ設計（閃光なし）。

| 項目 | 悲劇用 |
|---|---|
| ねらい | 演出はハイテンションなギャンブル風、中身は救いのない後味の悪い実話。明るさと結末の落差で見せる |
| 題材 | 命を懸けたが実らなかった／最後まで認められなかった／最後は哀しい死を遂げた、の実話。事実確認はいつもどおり（ChatGPT の依頼文 → Claude が出典で確かめ直す → ユーザーの「OK」） |
| ギャンブル | **テンションだけ**（勝負に出る高揚・一発逆転の期待・外れたときの落差）。スロット・カード・チップ・ルーレットなどの器具や、オッズ・賭け金の表示は画面に出さない（2026-10-30 ユーザー） |
| 効果音 | ドパ設計よりさらに派手に（打ち込み・上昇音・決めの一打・落ちる音を多めに、テンポを速く） |
| BGM | 拾える素材からハイテンションな曲を選ぶ（無料・商用可・YouTube の収益化で使えるものだけ。課金しない。権利は `scripts/pilot_NNN/assets.md` に記録） |
| 動き | 人物やオブジェの動きも派手に（大きく跳ねる・回る・飛び込む・積み上がって崩れる） |
| 画面の文字 | `slam()`・`popSub()`（ドパ設計と同じ。残りの距離・日数などの数字を大きく叩きつける） |
| ナレーション | ハイテンション気味（話者・スタイル・話速・抑揚は聞き比べで決める） |
| 閃光 | 使わない（ドパ設計と同じ） |

- 事実は誇張しない。亡くなった人をあざける言い方はしない（ハイテンションにするのは「賭け」の演出で、死そのものを笑いにしない）。

## 4 つ目：「悲劇」（2026-10-30、ユーザーが命名。悲劇用を直した版。参考：pilot_020 v2 スコット）

指示で「悲劇で」と言われたら、この設定で作る。**悲劇用の演出（勝負のテンション・派手な動き・叩きつける文字）はそのままに**、次を変える（ユーザー「さすがに全体的に不謹慎なので」）。

| 項目 | 悲劇 |
|---|---|
| 全体の流れ | **序盤はコテコテ**（BGM・効果音・演出を盛り、色も派手に）。**動画の 1/3 くらいから**、話の起承転結に合わせて少しずつ演出をシリアスに、BGM を静かにしていく（変化がはっきり分かるように）。**最後は環境音と静かなナレーション、暗めの画面で終わる**（2026-10-30 更新。以前は「後半 2/3 から」） |
| 声 | **ナレーターは最初から最後まで同じ人**（叫ぶ声などの話者の切り替えはしない）。序盤は話速 1.5（聞き取れる限界近く）・抑揚 1.7。1/3 くらいから行ごとに少しずつ**静かで落ち着いた声に、少しだけゆっくりに**（`lines.json` の行ごとの `speed`・`inton`・`pitch`）。**最後の一言はゆっくり、はっきりと**（例：話速 1.0 前後、行の前に間をとる） |
| BGM と環境音 | **短調で、リズミカルな曲**（荘厳なオーケストラは避ける。拾える素材から。調は `production/voice_tests/keycheck.py` で確かめる）。1/3 くらいから**曲は少しずつ静かに、最後は無音**、**吹雪などの環境音だけを残す**（`bgm_file.py` のモード `mXXwYY`＝曲 XX%・環境音 YY%、`smooth=3.0`。環境音は合成） |
| 色調 | **序盤は派手に色を使う** → 1/3 くらいから少しずつ彩度を落とし、冷たく、暗く → **最後は暖色のない、静けさを感じる暗めの画面**（renderer の `darkK(t)` を 1/3 から） |
| 文字・字幕 | 前半は `slam()`・`popSub()`。**ラスト（最後の日記〜）は明朝体の真面目な字体**（しっぽり明朝、OFL。`calmText()`・`calmSub()`：揺れ・跳ね・光なし） |
| 画面の一打・効果音 | 序盤は多く派手に、1/3 くらいから少しずつ減らし弱める |
| 終わり方 | **共通エンディング（「リバース」）はカット**（`production/ext/noend_ext.py`。CLAUDE.md の「全動画に共通エンディング」の例外、ユーザーの指示）。最後の一文のあと、**時間をかけて暗転（最低 2 秒、標準 2.6 秒：`noend_ext.apply(pipeline, black=2.6)`）**。暗転のあいだは環境音だけ |

- 悲劇用の決まり（器具を出さない・閃光なし・あざけらない・死の瞬間を見せない・自死の題材を避ける）はそのまま。
- 実際の死亡の瞬間の映像・写真は使わない（CG で暗示する）。自死の題材は避ける。

## オープニング（冒頭 約 3 秒のタイトル。2026-10-30〜、pilot_021 で始め、ドパ設計にも使う）

- 動画の結論を文字にして画面の上〜中ほどに大きく、**本編とは別の声**（冥鳴ひまり）がはっきり読む。本物の写真を画面の中央に、背景は動く CG。字幕は出さない（SRT には入れる）。
- BGM は本編と別。悲劇は不安定なホラー調（`bgm_file.py` のモード `h`）。知的設計・ドパ設計では **駆け上がるベルのチャイム**（`ext/opening_bgm.py` のモード `open_chime`。pilot_022 で、やさしい音〔`open_soft`〕は「微妙」、少し不気味な音〔`open_eerie`〕は「あるチャンネルの音に酷似」とされ、3 回目に決定）。
- 中央の本物の写真は**グロテスクなものを避ける**（菌・ウイルスの電子顕微鏡写真、病変、傷など。pilot_022 で「ややグロテスク」→ グレイ解剖学の線画に差し替え）。
- 作り方は pilot_021（`lines.json` の L00〔who W〕、renderer の `openingUI()`・`fx2open()`）。

## 話が大きく変わるところ（すべての設計、2026-10-30〜）

- 物語の転換点（例：pilot_022 で、マーシャルが自分の体で試すと決める L08）は**大きく演出し、カットを切り替えて驚きを出す**：一瞬の暗転に大きな文字 → 被写体の極端な寄り → 別の角度 → 引き、と効果音の一打ごとにカットを切る（0.5〜0.7 秒ずつ）。BGM は直前で一度引いて、切り替わりで入れ直す。閃光は使わない。
- 画面の札は一文字のアイコン（「ス」など）を付けず、文字だけにする（pilot_022 で「変」とされた）。

- ドパ設計でも事実は誇張しない（叩きつける言葉も台本と事実確認の範囲で）。文字の自動検査・顔が映らないことの確認は同じように行う。
