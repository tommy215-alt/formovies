## 3 つ目：「悲劇用」（2026-10-30、ユーザーが命名）

指示で「悲劇用で」と言われたら、この設定で作る。土台は v2.4 とドパ設計（閃光なし）。

| 項目 | 悲劇用 |
|---|---|
| ねらい | 演出はハイテンションなギャンブル風、中身は救いのない後味の悪い実話。明るさと結末の落差で見せる |
| 題材 | 命を懸けたが実らなかった／最後まで認められなかった／最後は哀しい死を遂げた、の実話。事実確認はいつもどおり（ChatGPT の依頼文 → Claude が出典で確かめ直す → ユーザーの「OK」） |
| ギャンブル | **テンションだけ**（勝負に出る高揚・一発逆転の期待・外れたときの落差）。スロット・カード・チップ・ルーレットなどの器具や、オッズ・賭け金の表示は画面に出さない（2026-10-30 ユーザー） |
| 効果音 | ドパ設計よりさらに派手に（打ち込み・上昇音・決めの一打・落ちる音を多めに、テンポを速く） |
| BGM | 拾える素材からハイテンションな曲を選ぶ（無料・商用可・YouTube の収益化で使えるものだけ。課金しない。権利は `scripts/pilot_NNN/assets.md` に記録） |
| 動き | 人物やオブジェの動きも派手に（大きく跳ねる・回る・飛び込む・積み上がって崩れる） |
| 画面の文字 | `slam()`・`popSub()`（ドパ設計と同じ。残りの距離・日数などの数字を大きく叩きつける） |
| ナレーション | ハイテンション気味（話者・スタイル・話速・抑揚は聞き比べで決める） |
| 閃光 | 使わない（ドパ設計と同じ） |

- 事実は誇張しない。亡くなった人をあざける言い方はしない（ハイテンションにするのは「賭け」の演出で、死そのものを笑いにしない）。

## 4 つ目：「悲劇」（2026-10-30、ユーザーが命名。悲劇用を直した版。参考：pilot_020 v2 スコット）

指示で「悲劇で」と言われたら、この設定で作る。**悲劇用の演出（勝負のテンション・派手な動き・叩きつける文字）はそのままに**、次を変える（ユーザー「さすがに全体的に不謹慎なので」）。

| 項目 | 悲劇 |
|---|---|
| 全体の流れ | 前半 1/3 は勝負のテンション。**後半 2/3 から少しずつ、話のトーンと演出を暗くしていく** |
| 声 | 前半は話速 1.5（聞き取れる限界近く）・抑揚 1.7。後半 2/3 で行ごとに少しずつ下げる（例：話速 1.5 → 1.32、抑揚 1.7 → 0.9、高さ +0.03 → −0.05。`lines.json` の行ごとの `speed`・`inton`・`pitch`）。叫ぶ声は前半の要所だけ |
| BGM | **短調**の曲（拾える素材から。調は `production/voice_tests/keycheck.py` で確かめる）。後半は段階的に下げ（`bgm_file.py` の `f_85`〜`f_15`）、**最後は無音** |
| 色調 | **全体に冷たく**（暖色を使わない。文字の金色も氷の色に）。後半ほど彩度を落とし、暗くする（renderer の `darkK(t)`） |
| 画面の一打 | 後半ほど弱める |
| 終わり方 | **共通エンディング（「リバース」）はカット**、最後の一文のすぐあとに暗転して余韻を残さない（`production/ext/noend_ext.py`。CLAUDE.md の「全動画に共通エンディング」の例外、ユーザーの指示） |

- 悲劇用の決まり（器具を出さない・閃光なし・あざけらない・死の瞬間を見せない・自死の題材を避ける）はそのまま。
- 実際の死亡の瞬間の映像・写真は使わない（CG で暗示する）。自死の題材は避ける。

- ドパ設計でも事実は誇張しない（叩きつける言葉も台本と事実確認の範囲で）。文字の自動検査・顔が映らないことの確認は同じように行う。
