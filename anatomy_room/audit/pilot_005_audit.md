### 導出の再検算（D1）

```
(−2) × (3 + (−3)) = (−2) × 0 = 0
分配法則より (−2) × 3 + (−2) × (−3) = 0
(−6) + (−2) × (−3) = 0
よって (−2) × (−3) = 6
```

各段の値を確認した（−6 + 6 = 0）。画面の式（`renderer.html` の `sceneDerive`）と字幕（`lines.json` L18〜L21）も同じ値で、読み上げ文とも一致することを照合した。

## B. 教育上の正確性

- **見た後に理解すること**：負×負が正になるのは、負の数でも分配法則などの計算ルールを保とうとすると、それ以外に選べないから。
- 面積図が負の数の証明に見えないよう、「正の数での例」と表示し、負の数の場面では図を消して式で示す。
- 数直線の反転は「見方」の一つ。導出の代わりにしない。
- 冒頭の借金の比喩（「借金×借金＝大借金」）は、W が「借金に借金を掛けるって、どういう状況？」と矛盾を指摘し、最後に M が「借金は、掛けるもんじゃなかった」と回収する。比喩が事実として残らない。
