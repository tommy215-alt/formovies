1. ユーザーが ChatGPT レビューを完了した
2. ユーザーが採用するシナリオを明示的に指定した
3. 声・外見などのキャラクター仕様が決まった

予定しているファイル名：`pilot_00N/final_short.mp4`、`pilot_00N/subtitles.srt`、`pilot_00N/narration.wav` など。
