## メモ（台本の外）

- **見せ方の山**：月〜木は軽いテンポ（数千円ずつ）→ 金曜で暗転して一気に 1,240 万円 → 土曜で明るく戻る → 結果 → 実在の人物で「でも、悪いことばかりではない」→ 最後の問いで冒頭へ。
- 金曜の 1,240 万円は「SNS 型投資・ロマンス詐欺の 1 件あたり平均」（被害額 ÷ 件数の計算）。主人公の被害額ではなく「平均ならこれくらい」と分かる言い方にする（L09）。
- 月〜土の金額のうち、飲み会（4,237 円）だけが調査の平均。大盛り・保証・プラン・寄付は**この動画の仮定**（fact_check.md の A）。画面には出すが、ナレーションでは言わない。
- 詐欺の場面は手口をまねできるように描かない（通知の一言だけ）。
