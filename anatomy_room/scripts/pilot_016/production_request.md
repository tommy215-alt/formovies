# pilot_016 制作指示：大陸は動いている——アルフレート・ヴェーゲナー

> 2026-10-29 作成（ユーザーの指示：ネタの 3 を採用）。標準ルール v6・ガイドライン v2.2 にもとづく。事実確認は ChatGPT に `gpt_fact_check_prompt.md` で依頼し、Claude が出典で確かめ直す。台本はユーザーの「OK」で制作を始める。

## 1. 題材と物語

- **題材**：アルフレート・ヴェーゲナー（1880〜1930）。1912 年に大陸移動説を発表し、受け入れられないまま 1930 年にグリーンランドで亡くなった。1950〜60 年代、海底の研究（海底の地図、磁気の縞模様、海洋底拡大）を経て、プレートテクトニクスとして正しさが認められた。
- **一つの疑問（最後まで追う）**：大陸は本当に動くのか。なぜ正しい考えが、長く受け入れられなかったのか。
- **冒頭（ガイドライン v2.2 の 2）**：最初の 0.5〜1 秒に、決定的な映像（アフリカと南アメリカの海岸線が、パズルのようにぴたりと合わさる）を先に見せる。答え（プレート・名前）は言わない。続けて問い。
  - 冒頭の一文（案）：「この二つの大陸は、もとは一つだった。そう言った男は、信じてもらえないまま、氷の上で亡くなった。」
- **物語の核**（事実確認のあと `fact_check.md` の冒頭に出典つきで書く）：
  - 状況：大陸は動かないと考えられていた（大陸のあいだの陸橋が沈んだ、などの説明）。
  - 具体的な困難：気象学者で、地質学の専門家ではなかった。大陸を動かす力を説明できなかった。
  - 本人の行動：海岸線の形、海をはさんで同じ化石・同じ地層・昔の気候の跡を集め、本にまとめ、改訂を重ねた。
  - 転機：本人の死後、海底の研究で、大陸が動く仕組み（海底が広がる）が分かった。
  - 現在：GPS で大陸が年に数 cm 動いているのを測れる。地震・火山の仕組みの理解。
- **最後（ガイドライン v2.2 の 3）**：最後の一文で冒頭の問いに答え、最後の画は冒頭の「合わさる大陸」に戻す。
- **長さ**：本編 60〜90 秒（全体 95 秒以内）。

## 2. 本物の写真・図（ガイドライン v2.2 の 4）

- 候補：ヴェーゲナーの肖像写真（1910〜1930 年ごろ）、本人の著書『大陸と海洋の起源』（1915・1929 年版）の図（大陸の位置の図、化石の分布の図）、グリーンランド探検の写真。
- 本人は 1930 年に死去しているため、本人の著書の図は多くの国で著作権が切れていると考えられる。写真は撮影者が別のことがあるので、1 枚ずつ所蔵先の権利の表示を確かめる。確認は ChatGPT の依頼文に含め、Claude が所蔵先のページで確かめ直し、`assets.md` に記録する。
- 使うのはパブリックドメイン・CC0・CC BY だけ。
