# pilot_015 制作指示：太陽は何でできているか——セシリア・ペイン

> 2026-10-29 作成（ユーザーの指示：ネタの 9 を採用。これまでの設計＝標準ルール v5・ガイドライン v2.1・rv にもとづく。ChatGPT のレビューは使わず、Claude が自己レビューし、ユーザーが判断する）。

## 1. 題材と物語

- **題材**：セシリア・ペイン（のちのペイン＝ガポーシュキン、1900〜1979）。1925 年の博士論文で、星の大部分が水素とヘリウムであることを示した。
- **一つの疑問（最後まで追う）**：太陽は何でできているのか。なぜ正しい答えが「ありえない」と言われたのか。
- **冒頭の一文（案）**：「太陽は何でできているか。正しい答えを書いた彼女は、『ありえない』と言われた。」
  - 生む問い：「なぜ正しいのに否定された？」「本当の答えは？」
  - 名前は 2 行目まで出さない。答え（水素）は核心の場面まで言わない。
- **物語の核**（`fact_check.md` の冒頭に、出典つきで書く）：
  - 状況：当時は「太陽の成分は地球とだいたい同じ（鉄などが多い）」と考えられていた。
  - 具体的な困難：イギリスでは女性に学位が与えられなかった。アメリカへ渡ってからも、若い女性の研究者だった。
  - 本人の行動：星の光を虹色に分けた帯（スペクトル）の黒い線を数十万枚の写真乾板から読み取り、新しい理論（サハの電離の式）で、星の温度と成分を計算した。
  - 転機：水素が地球の何十万倍も多いという結果が出た。権威のヘンリー・ノリス・ラッセルに「明らかにありえない」とされ、論文に「おそらく本当ではない」と書き添えた。
  - 結果：数年後、ラッセル自身が別の方法で同じ結論を出した。彼女の論文は「天文学で最も優れた博士論文」と呼ばれるようになった。のちにハーバードで女性として初めての教授・学科長になった。
  - 現代での意味：宇宙の普通の物質の大部分が水素であること。星の一生、核融合の研究、宇宙の成り立ちの理解につながる。
- **事実確認で特に注意すること**（確認できないものは台本に入れない、または「〜とされる」）：
  - 乾板の枚数、水素の量の倍率、ラッセルの言葉の原文と時期、論文に書き添えた文の原文。
  - 「天文学で最も優れた博士論文」と言った人物（オットー・ストルーヴェとされる）。
  - ケンブリッジで女性に学位が与えられなかった時期。「最初の〇〇」の範囲（ラドクリフ／ハーバードの天文学の博士号など）。
  - ラッセルを悪人として描かない（当時の常識と証拠の状況）。手柄を奪ったと断定しない。
- **長さ**：本編 95〜110 秒＋共通エンディング。

## 2. 今回の修正事項（ユーザーの指示、2026-10-29）

1. **BGM**：テンポは今と同じ 124 BPM のまま。無機質な音色をやめ、安心して聴ける曲調にする。場面ごとに変えるのは続ける。
   - 案：長調中心の温かい和音（エレクトリックピアノ・やわらかいパッド）、丸いキック、柔らかいベース、金属的な打音と低いうなりは使わない。場面の感情に合わせて「静かな謎 → 集中 → 壁（少し陰る。短調に寄せすぎない）→ 発見（明るく開く）→ 余韻」と変える。
   - 確認：qc の BPM（124）、音量（−14 LUFS）、ナレーションの帯域（1〜4 kHz）に重ねない。
2. **冒頭 3 秒**：問いかけと合わせて、文字・効果音・光をまとめて強くする。
   - 1 秒目：暗闇に太陽の光が差し込み、画面いっぱいの太字の問い「太陽は何でできている？」（字幕とは別の、大きな見出しの文字。光とともに出る）＋低い一打と光の広がりの音。
   - 2〜3 秒目：「ありえない」の文字に赤いスタンプのような判（効果音つき）。続きを見る理由（なぜ否定された？）を 3 秒以内に示す。
   - 確認：`qa/hook_3s.mp4` を見て「続きを見たいか」を判断する。最初のコマが止め絵として成り立つか。
3. **CG**：今の品質（cine.js）のまま。対象に注目するとき・寄るときは、テクノロジー感のあるアイコンと演出を入れる。
   - 例：照準の円と四隅の枠（今の hudTarget・hudBox）に加えて、スキャンの線、拡大鏡の枠と倍率の表示（×10・×100）、データの読み込み表示、元素記号のタグ（H・He・Fe）、スペクトルの線を指す引き出し線。
   - 一画面に出しすぎない。字幕と被写体を隠さない。
4. **効果音を増やす**：場面転換、注目マーク、数字・文字の出現、拡大、発見の瞬間に入れる（pilot_014 の約 30 個より多く。目安 45〜60 個）。
   - やわらかい音色のまま。耳に刺さる高音、同じ音の短い連打は避ける。BGM・効果音・ナレーションが同時に主張しないようにする。
5. **セリフを速く**：聞き取れる範囲で、今より速くして情報量を増やす。
   - 目安：pilot_014（話速 1.12、6.7 モーラ/秒）から約 1 割速く（7.3〜7.6 モーラ/秒）。重要な数字と転機の前後の間は残す。
   - 確認：`measure_tts.py` で実測し、qc の「文末の音程」「読み上げの照合」を見る。速すぎて聞き取りにくい行は、文を短くする。

## 3. 標準のまま使うもの

- 構成：フック → 対象 → 背景・仕組み → 核心 → 余韻 → 共通エンディング（`REVERSE_STANDARD_RULES.md` v5、ガイドライン v2.1）。
- 映像：暗めのテック調。色調は `moodGrade` で感情に合わせて変える。人物は顔のない人形、手のアップは使わない。左上のロゴなし、注記は必要最小限（再現 CG の注記は人物が最初に出る場面で 1 回）。
- 字幕：62px・1 行 15 字まで、重要な文字は 1.2 倍。
- 決定的な映像：太陽の光がスペクトルの帯にほどけ、黒い線に元素の名前のタグが付き、最後に H の線だけが強く光る瞬間（BGM は発見の明るい和音、効果音は発見の音）。
- 声：題材（科学・宇宙）と雰囲気に合わせて VOICEVOX から選ぶ（ガイドライン v2.1 の表。候補は玄野武宏・黒沢冴白・冥鳴ひまり。使う前に話者の利用規約のページを確認する）。
- 書き出し：`python anatomy_room/tools/rv.py 015 render all`（変わった場面だけ）。確認は `preview scene N`。完成前の最後に `--full`。
- 完成チェック：`VIDEO_QA_CHECKLIST.md`（G1〜G11）、`video_qa.py --sheets`、冒頭 3 秒の切り出し、全コマの目視。
- YouTube への投稿はしない。課金しない。

## 4. 進め方と、止まる所

1. 事実確認（`scripts/pilot_015/fact_check.md`、物語の核を先に）→ 台本（`production/pilot_015/lines.json`）→ 尺の実測。
2. **ここで止めて、ユーザーに台本を見てもらう**（ChatGPT のレビューの代わり。ユーザーの「OK」が制作の開始条件）。
3. 演出の設計（BGM の新しい曲調、効果音、注目のアイコン）→ 冒頭 3 秒と決定的な映像の静止画をユーザーに見せる。
4. 全場面の静止画 → 書き出し → 検査 → 報告（保存先・変更点・確認したこと・制約）。
