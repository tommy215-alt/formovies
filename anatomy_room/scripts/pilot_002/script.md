# pilot_002：蛇口の水は、誰が押している？

## 1. 基本情報

| 項目 | 内容 |

| タイトル | 蛇口の水は、誰が押している？ |
| テーマ（分野） | インフラ（水道） |
| 視聴者が得る学び | 水道水は、①川やダムの水を ②浄水場で「固めて沈める → 砂でこす → 塩素で消毒」し ③高台の配水池から、水の重さ（高低差）やポンプの力で押し出している。水道管の中は常に水で満たされ、押された状態で待っているので、ひねった瞬間に水が出る。塩素はわざと蛇口まで残している |
| 想定尺 | 約 90 秒 |

| 想定する視聴者の疑問 | 蛇口をひねるとすぐ水が出るのはなぜ？ 水道の水はどこから来て、どうやってきれいになっているの？ |
| 主な CG 表現 | 浄水場の工程を横スクロールで見せる断面図／濁りの粒子がくっついて沈むミクロ表現／高台から街まで、水道管の中の水圧を色の濃さで見せる透視図／蛇口の内部断面 |
| 掛け合いの型 | M：素朴な勘違い（蛇口に水が詰めてある）＋「コーヒーフィルター」の発想 ／ W：具体的な矛盾で返し、M の発想を部分的に認める |

## 2. フック（冒頭 3 秒）

- **セリフ**：M「蛇口の中ってさ、水がギッシリ詰めてあるんだろ？」→ W「その量だと、コップ一杯で品切れね」
- **映像**：キッチンの蛇口をカメラが透視すると、蛇口の中に小さな水のタンクが入っている（M の想像。手描き風）。W の返しと同時に、コップ一杯でタンクが空になり「品切れ」の札がぶら下がる。
- **狙い**：毎日使う蛇口に、誰も考えたことのない疑問を投げる。W の返しは「規模が合わない」という具体的な矛盾で、視聴者も一緒に「じゃあどこから？」と考え始める。
