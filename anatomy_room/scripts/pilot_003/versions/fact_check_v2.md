## 4. 事実確認リスト

### FACT-01
- **主張**：ごはん（水分が多い）と焼き海苔（乾燥している）を接触させておくと、水分がごはんから海苔へ移り、海苔がしっとりする。家庭で作るおにぎりは、海苔を最初から巻く（直巻き）ことが多く、海苔はしっとりしている。
- **台本中の該当箇所**：「家で作ったおにぎりの海苔は、どうなってる？」、「しっとりしてる」、「ごはんは水分たっぷり、海苔はカラカラ。くっつけておくと、水分がごはんから海苔へ移っていくの」、「雑だけど、そういうこと」
- **出典**：S1, S2, S3
- **検証結果**：QUALIFIED
- **注意点**：(a) 水分活性の高い成分から低い成分へ水分が移動し、乾いた成分のサクサク感が失われる現象（moisture migration）は食品科学の一般的な原理で、米国特許の背景技術（例：ピザのソースから生地へ水分が移ってべちゃっとなる）で確認した。ごはんと海苔そのものについて述べた一次資料は今回見つけられなかったが、原理の適用として妥当と判断。(b) 「家庭は直巻きが主流で、海苔はしっとりしていた」は、セブン‐イレブンの担当者のコメント（東京ウォーカー記事）で確認。(c) 海苔が湿気に弱いことは海苔業界の取材記事（ウェザーニュース）で確認。(d) ごはん・海苔の **具体的な水分値**（例：ごはん約 60%）は、日本食品標準成分表の本文で確認できなかったため、台本では数値を使わない。
- **修正が必要か**：不要（数値を出さない定性的な説明にとどめている）

### FACT-02
- **主張**：コンビニの手巻きタイプのおにぎりは、海苔を 2 枚のフィルム（内側・外側）で挟み、海苔とごはんが食べる直前まで触れないように包装している。
- **台本中の該当箇所**：「海苔とごはんの間に、フィルムの壁を作ってるの」、「海苔は、2枚のフィルムに挟まれてる」、「別居。いい言葉ね」、「食べる直前まで別居」
- **出典**：S4, S1
- **検証結果**：VERIFIED
- **注意点**：特許公報 JPH07274870A「包装おにぎりとその製造方法及び包装フィルム」で「内外フィルム間に海苔を挟んだ包装フィルムで包装」する構成を確認した。また、先行技術として「外フィルムの内側に海苔を重ね、さらにその内側に内フィルムを配置する」包装が挙げられている。セブン‐イレブンの担当者も「食べる直前にパリパリの海苔を巻けるようおにぎりと海苔を分けて包装する」と説明している（東京ウォーカー記事）。フィルムの細部の構造はメーカー・時期によって異なる。
- **修正が必要か**：不要

### FACT-03
- **主張**：一般的な手巻きおにぎりの包装は、①中央の開封テープを引いてフィルムを真ん中で裂き、②③左右のフィルムを横に引き抜くと、フィルムだけが抜けて海苔がごはんの上に残る。番号どおりに開けないと、海苔が破れやすい。
- **台本中の該当箇所**：「まず①のテープを下まで引くと、フィルムが真ん中で裂ける」、「次に②と③で、左右のフィルムを引き抜く。フィルムだけがスルッと抜けて、海苔がごはんの上に残るの」、「だから番号どおりに開けるのがコツ。順番を飛ばすと、海苔が破れやすいの」
- **出典**：S5, S6, S7, S8
- **検証結果**：QUALIFIED
- **注意点**：開封手順は、訪日客向け解説（tsunagu Japan「1 の矢印に沿って下までビニールを剥がし…左右のフィルムを外す」）、国際交流基金の日本語教材（ERIN「ツマミを手前に引き上げ、そのまま裏側まで回して取る」）、解説記事（jeepe「番号や矢印の順に外すと海苔がパリパリのまま取り出せる。無理に一度で開けず順番どおりに」）で確認した。いずれも二次資料で、**メーカーの公式な構造説明や、この方式の特許文書の本文は確認できていない**（JPH07274870A はミシン目で両端を切り離す別の構成）。テープがフィルムのどの層を裂くかなど、細部は確認できなかったため、台本では「フィルムが真ん中で裂ける」とだけ言い、「外側だけが裂ける」とは言わない。映像の透視表現はこの不確かさを踏まえ、層の厚みや接着位置を誇張しない模式図にする。
- **修正が必要か**：不要（ただし CG 制作前に、実物の包装を分解して構造を確認することを推奨）

### 削除した主張：旧 FACT-04
- **v2 で台本から削除**（理由は audit/ の監査報告書）
- **主張**：海苔とごはんを分けて包装する手巻きおにぎりの方式は、1970 年代の終わりごろ（1978 年とされる）にコンビニで登場した。
- **台本中の該当箇所**：「この別居スタイルは、1970年代の終わりごろ、コンビニで登場したと言われてる」
- **出典**：S9, S1, S10
- **検証結果**：QUALIFIED
- **注意点**：おにぎり協会代表理事のコメントとして「1978 年にセブン‐イレブンが考案した包装が、海苔をパリパリに保つ手巻きおにぎりの先駆け」（GetNavi web）、セブン‐イレブン担当者のコメントとして「約 50 年前」から販売（東京ウォーカー記事）を確認した。**いずれも報道記事で、企業の公式な年表は確認できていない**。また「最初」「発明」と言える根拠はない。さらに、1970 年代のコンビニではおにぎりがほとんど売れなかったという報道（PRESIDENT Online、S10）もあり、初稿の「広まった」は時期として不正確になりうるため、自己レビューで「登場したと言われてる」に修正した。企業名・「世界初」などは出さない。
- **修正が必要か**：不要（年代を出さない案も ChatGPT に相談する）
