# pilot_051 事実確認（もしも設計）「猫 何匹で、新幹線は動く？」

> 2026-11-11。計算は `sim/cats.py`（結果 `sim/results.md`・`cats.json`）。
> 確認方法：「本文」＝WebFetch で本文から読んだ。「検索の要約」＝WebSearch の要約・抜粋で確認（本文は未確認）。「目安」＝出典のない仮定。

## 条件（ユーザー）

- 案 6（カブトムシ 何匹で新幹線は動く？）を採用し、カブトムシを猫に変える。細かい条件（車両・猫の力）は Claude が決め、流れを見せて OK をもらう。

## 元の値

| 値 | 使った数 | 出典・確認方法 |
|---|---|---|
| 列車の重さ | 700 t（16 両） | N700S の計画「700 t 以下」（乗りものニュースの記事、検索の要約）。実際の重さの公式の値は未確認 |
| 編成・モーター | 16 両（電動車 14・付随車 2）、主電動機 305 kW、長さ 404.7 m | ja.wikipedia「新幹線N700S系電車」（本文）。305 kW × 56 台 ＝ 17,080 kW は Claude の計算 |
| 動き出すときの抵抗 | 30 N/t（ころ軸受） | ja.wikipedia「列車抵抗」（本文） |
| 進むときの抵抗 | g(1.273 + 0.001v + 0.0001381v²) N/t（100 系、v は km/h）→ 時速 2.4 km で 12.5 N/t | 同（本文）。N700S の式ではない |
| 坂の抵抗 | 1‰ あたり 9.8 N/t | 同（本文） |
| 一番きつい坂 | 20‰ | ja.wikipedia「東海道新幹線」の基本情報（本文） |
| 東京〜新大阪 | 実際の距離 515.4 km、最速 2 時間 21 分、最高 時速 285 km | 同（本文） |
| 猫の体重 | 4 kg（多くは 2.5〜7.5 kg） | ja.wikipedia「ネコ」（本文） |
| 猫の最高の速さ | 時速 約 48 km（短い間） | 同（本文） |
| 猫の歩く速さ | 秒速 0.67 m（±0.22） | 健康な猫 12 匹の歩行の計測（検索の要約） |
| 猫の眠る時間 | 1 日 12〜16 時間 | 一般向けの資料（検索の要約）。画面は 14 時間 |
| 荷を引く動物の力 | 牛は体重の 10〜12%、馬・ラクダは 12〜14% を引き続けられる | FAO の資料（検索の要約） |
| 日本の飼い猫 | 約 885 万匹（2025 年） | 二次資料（検索の要約）。ペットフード協会の公式の報告は未確認。令和 6 年は 約 916 万匹という値もある → 画面は「約 7 割」 |

## 仮定（説明文の「計算の条件」に書く）

| 仮定 | 内容 |
|---|---|
| 猫の引く力 | 引き続ける力＝体重の 10%（3.9 N）、一瞬の力＝体重の 50%（19.6 N）。猫が物を引く力の研究は見つかっていない |
| 向き | 全員が同じ向きに、同時に引く。綱・胴輪の重さと伸びは考えない |
| 線路 | 平らでまっすぐ。風なし。ブレーキはゆるめてある |
| 1 日に歩く時間 | 10 時間（14 時間は寝る） |
| 猫の列 | 横 25 匹・前後 0.6 m（列の長さの計算だけに使う） |

## 映像の注意

- 車両は白い流線形のオリジナル。特定の会社のロゴ・帯の色・形式名は出さない。
- 猫の胴輪・綱、蝶、屋根での昼寝は演出。猫が痛がる・けがをする画は描かない。
