# pilot_060 YouTube

## タイトル

もし日本だけの「終末時計」があったら、いま真夜中まで何秒？ #shorts

## 説明文

真夜中＝日本の人が一人もいなくなる時。人口の10分の1を失うごとに1分進む、という、この動画だけの物差しで、日本の歴史をはかりました。
737年の天然痘、天明の飢饉、関東大震災、戦争、東日本大震災。そして、いま進んでいる人口減少。

※時計はこの動画の仮定です（秒＝60×log10(1÷失った人口の割合)）。本物の終末時計（原子力科学者会報）とは関係ありません。
※2070年・2120年の人口は、国立社会保障・人口問題研究所「日本の将来推計人口（令和5年推計）」の推計です。
