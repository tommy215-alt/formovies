# pilot_065 シーン設計（CG 演出）：2013年まで、選挙に行けなかった日本人

`production_script.py docs` が生成（時間は実際の音声にもとづく）。描画は `renderer.html`。

## 演出の方針

- 新ドパ設計 v2（061 型）：3D（Blender）。体育館の投票所の扉が閉まる → 居間で選挙公報と入場券 → 朝の住宅街を両親と → 後見人の書類 → 郵便受けに彼女のはがきだけ来ない → 資料室の条文の石板 → 天秤（電卓と投票用紙）→ 法廷 → 国会の議場で一斉に起立 → はがきが 3 枚そろう → 投票所の扉が開き、一票が箱へ。
- 説教臭くしない：責める言葉・べき論なし。人は顔のない模型、実名・写真なし。閃光・点滅なし。
