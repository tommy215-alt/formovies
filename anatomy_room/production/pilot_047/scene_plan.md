# pilot_047 シーン設計（CG 演出）：毎日2倍になる隕石。地球は何日もつ？

`production_script.py docs` が生成（時間は実際の音声にもとづく）。描画は `renderer.html`。

## 演出の方針

- もしも設計の既定（pilot_045 v2.3）。ナレーション・BGM なし。毎日の正午に向けて時計が刻み、隕石が毎日 2 倍になる。
- 閃光は使わない：衝突は「一瞬音が消える → 低い衝撃 → 地鳴り」と、揺れ・煙・色の変化で見せる。人は逃げる（崩れる街は無人）。
