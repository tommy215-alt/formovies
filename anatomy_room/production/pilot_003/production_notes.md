## 作り直し方

```bash
# 0) VOICEVOX ENGINE（CPU 版 0.24.1）を 127.0.0.1:50021 で起動しておく（第 1 話の production_notes.md と同じ）
cd anatomy_room/production/pilot_003
python3 production_script.py all       # voice → audio → render → mux → docs → qc
python3 production_script.py update    # lines.json を直した後（変えた行の音声と、変わった場面の映像だけ作り直す）
node render_frames.js --stills 12.5,60.8   # 指定した秒のコマを work/stills/ に（確認用）
```

- 3D の描画は GPU のない環境でブラウザ 1 つあたり 1 秒に約 0.7 コマ。3 並列で全編 約 35〜40 分（第 1 話の 2D の約 4 倍）。
  場面ごとに保存して再利用するので、セリフ 1 行の修正なら、その場面だけ（数分）で済む。
- 長時間の書き出しがツールの時間制限で止まっても、書き終わった場面は保存されている。同じコマンドをもう一度実行すれば続きから書き出す。

### 声について

- 声の選び方：VOICEVOX の話者を同じ文で合成し、声の高さ（中央値）と抑揚の幅を測って選んだ（`docs/CHARACTER_GUIDE.md`）。
  M は低く落ち着いた青山龍星、W は表情の大きい波音リツ。完成動画の音声から測ると、M 96 Hz・W 261 Hz（差 約 17 半音）。
- 「不機嫌」（M）と「クイーン」（W）のスタイルを行ごとに使い分けている（`lines.json` の `style`）。
- 共通エンディングは W（波音リツ・ノーマル）で、「リバース。」と「世界の仕組みを、はじめから。」を別々に合成し 0.5 秒の間を入れる。
- **投稿前の注意**：概要欄に「VOICEVOX:青山龍星」「VOICEVOX:波音リツ」を記載すること（エンドカードには表示済み）。
  青山龍星は、エンジンが案内する規約で法人の利用に事前確認が必要とされている。個人チャンネルとして使うか、法人として使うかを投稿前に確認し、規約の本文（制作環境のネットワーク制限で開けていない）を読むこと。

### 読み上げ

読みは VOICEVOX が実際に使ったカナで確認した（`qc_report.md` の「読み上げの照合」）。「水分＝スイブン」「着地＝チャクチ」「別居＝ベッキョ」。

## 実装の要点

- **3 層の画面**：背景（2D Canvas、場面ごとの明るい色）→ 3D（three.js、透明背景）→ 文字・字幕（2D Canvas）。
- **おにぎりの 3D モデル**：角の丸い三角形の押し出し形状。ご飯（粒の模様のテクスチャ）、海苔（深い緑、下半分）、外フィルム・内フィルム（半透明・反射）、中央のテープ。
  爆発図・開封の場面では、フィルムを左右で切り分ける「クリッピング面」を使い、層ごとに動かしている。
- **きっかけ**：映像・効果音のきっかけは「セリフ ID ＋そのセリフ内の位置」（`CUE_DEFS`）。音声の長さが変わっても追従する。
- **音**：BGM はセリフ中に約 62% 下げる。開封の直前（「……ここからが、見どころ」）で BGM を落とし、着地で戻す。全体を −14 LUFS・トゥルーピーク −2.0 dBTP に正規化。
- **字幕**：最大幅 860px を超えると自動で文字を小さくする。

## 品質検証の結果（2026-10-26、最終書き出し）

`qc_report.md` から：

- 映像 1080×1920、30fps、2692 フレーム、89.73 秒。音声 AAC 48 kHz、89.73 秒（最後のコマまで音声あり）
- 全編デコード：エラーなし
- ラウドネス −14.1 LUFS、トゥルーピーク −1.9 dBTP、無音区間（−45 dB 未満が 0.8 秒以上）なし
- 共通エンディング：最後のセリフとの間 0.98 秒（重なりなし）、2 句の間 0.52 秒、決めゼリフの区間の平均 −16.0 dB・−17.2 dB（完成動画から測定）
- 平均輝度 185.6/255（第 1 話は 36.6）、全 90 秒が輝度 80 以上
- 抽出フレーム 19 枚を目で確認：字幕・ラベルが画面からはみ出していない、字幕と主役の物体が大きく重なっていない

### 残っている小さな問題

- 9 秒付近と 45 秒付近に、動きの少ない区間が約 3.5 秒ある（目安は 3 秒以内）。
- 「正解」の字幕が 0.44 秒、エンディングの「リバース。」の音声が 0.75 秒と短い（「リバース」は画面の大きな文字が残るので読める）。

### 実施していない検証

- 人の耳による試聴（この環境では音を聞けない。音量・無音・声の高さは数値で確認した）
- スマートフォン実機での表示確認
- 実物の包装の分解による構造確認（開封の場面は「※模式図」と表示している）
