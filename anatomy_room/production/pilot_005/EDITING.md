# 第 1 話の直し方（短時間・少ない手間で）

## いちばん簡単な頼み方

Claude にこう伝えるだけで十分です（セリフ番号は `final_script.md` の「ID」列）。

- 「L01 のセリフを『〇〇〇』に変えて」
- 「L13 の字幕を『〇〇〇』に」
- 「冒頭（L01〜L03）を〜な感じに書き直して」
- 「W の話す速さを少し遅く」

Claude は `lines.json` の該当行だけを書き換え、次の 1 コマンドで作り直します。

```bash
python3 production_script.py update
```

## 何が作り直されるか

| 変更 | 作り直すもの | 目安の時間 |
|------|------------|-----------|
| 1 行のセリフ（読み上げ文）を変える | その行の音声だけ合成し直し → 音声ミックス → **その行を含む場面の映像だけ**書き出し → つなぎ直し → 検証 | 数分（場面の長さによる） |
| 字幕だけ変える | 音声はそのまま → その字幕が出る場面の映像だけ | 数分 |
| 間（pause）を変える | 音声ミックス → その場面の映像 | 数分 |
| 映像のデザイン（renderer.html）を変える | **全場面の映像**（3 並列） | 全編の書き出し |
| 声の種類・話速を全体で変える | 全行の音声 → 長さが変わった場面の映像 | ほぼ全編 |

### しくみ

- **音声**：読み上げ文と声の設定が同じ行は、前回の合成結果（`work/voice_cache/`）をそのまま使う。
- **映像**：動画を 11 の場面（冒頭・タイトル・パターン・反論・分配法則・橋渡し・導出・一般化・数直線・締め・エンドカード）に分けて書き出し、`work/segments/` に保存する。
  場面の中身（セリフの相対的な時間・字幕・きっかけ）が前回と同じなら、**前の場面の長さが変わって開始時刻がずれても、そのまま使い回す**。変わった場面だけ書き出し、最後に `ffmpeg` でつなぐ。
- 場面の境目で背景が飛ばないよう、背景（ドットと床のグリッド）は静止させている。
- 一度作った場面は残しておくので、修正を元に戻したときも書き出し直しは不要。

### 注意

- 1 行のセリフの長さが変わると、その場面の中の後ろのきっかけ（式が出るタイミングなど）も自動で追従する。ほかの場面には影響しない。
- 冒頭（L01〜L03）を変えた場合、作り直すのは「冒頭」「タイトル」の場面（合わせて約 12 秒）だけ。
- `work/` は Git に入れていない。新しい環境では最初の 1 回だけ全編の書き出しが必要（その後は差分だけ）。
- VOICEVOX ENGINE を 127.0.0.1:50021 で起動しておくこと（`production_notes.md`）。
